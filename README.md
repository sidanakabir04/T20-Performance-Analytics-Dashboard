# T20 Cricket Performance Analytics Dashboard

## 📌 Project Overview
This project demonstrates an end-to-end analytics workflow, from data extraction to interactive dashboard development.

T20 batting statistics were programmatically extracted from publicly available ESPNcricinfo pages using Python. The data was cleaned, structured, and analyzed using Power BI to evaluate player performance across multiple dimensions.

---

## 🔁 End-to-End Workflow

1. Web scraped player data using Python (requests + BeautifulSoup).
2. Cleaned and structured raw HTML tables using pandas.
3. Combined multiple player datasets into a consolidated dataset.
4. Built interactive Power BI dashboard with DAX measures.
5. Designed KPI-driven performance comparison visuals.

---

## 📊 Dashboard Features

- Batting Average KPI  
- Strike Rate KPI  
- Total 50s and 100s  
- Aggression vs Consistency scatter analysis  
- Opponent-wise performance comparison  
- Year-wise performance trend  
- Interactive player filtering
